# Portfolio de Martín Alvarez

Marketing digital y diseño. Sitio estático (HTML + CSS + JS, sin build), publicado en GitHub Pages. El formulario de contacto arma el mensaje y abre WhatsApp (ver `assets/main.js`).

- `index.html`: todo el sitio. Casos en la sección `#casos`, piezas en `#piezas` (masonry).
- Para sumar una pieza: guardar la imagen en `assets/img/` y copiar un `<button class="g" data-gallery="archivo.jpg">`.

Pendiente: foto de Martín, Instagram personal, más piezas de Pollería Bachi y El Oso.

Parte de [MGM Studio](https://mgm-studio.netlify.app).
